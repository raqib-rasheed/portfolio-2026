# Raqib Rasheed

Portfolio for a senior frontend engineer. Next.js 14, TypeScript, Tailwind, and Framer Motion.

The page is dark obsidian with a pointer-reactive mesh, a bento hero, three case previews, and a bottom dock. `⌘K` or `Ctrl+K` opens the command menu. Motion snaps off when reduced motion is requested.

The Deloitte case names Edward Jones, the investment-management project, and the SDLC agent. No invented metrics.
